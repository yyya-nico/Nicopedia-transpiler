# Nicopedia-transpiler
ニコニコ大百科の記事を作りやすく

Astroを使用しています。  
CSSもJavaScriptも自由に書いて、公開する前にインライン化とスクリプト実行→コピペでおしまい！を目指しています。

## For Developers
```
git clone https://github.com/yyya-nico/Nicopedia-transpiler.git
cd ./Nicopedia-transpiler
npm install
```

### 開発モードで起動
```
npm run dev
```

### buildして閲覧
```
npm run build; npm run preview
```
